\chapter{Introducción}
En este informe se describe el proceso llevado a cabo por los integrantes para desarrollar el proyecto final de la asignatura Compiladores, el cual comprende las etapas de análisis léxico, sintáctico y semántico, así como la generación de código. Estas fases se implementaron sobre TinyS, un lenguaje académico orientado a objetos.

Para la implementación del proyecto se utilizó Java SDK 21, sin emplear librerías externas. Asimismo, para la realización de las pruebas se utilizó la librería JUnit 6.
